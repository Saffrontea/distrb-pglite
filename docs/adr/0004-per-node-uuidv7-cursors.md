# ADR 0004: Per-Node UUID v7 Cursors

## Decision

Event IDs are UUID v7 generated by the source node. Replication progress is tracked per source node as `(source_node_id, event_id)`.

## Consequences

- No global ordering is inferred across nodes.
- Local wall-clock skew does not affect correctness across source streams.
- Snapshot metadata stores a high-watermark vector keyed by source node.
- `created_at` may be used for diagnostics, but never as a replication boundary.
